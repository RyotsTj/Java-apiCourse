# ドローン在庫管理 API (DroneInventorySystem)

製造業クライアント向けのドローン在庫管理システムです。

---

## 📘 カリキュラム概要

### 学習目的

本プロジェクトは【Java 開発コース】の実践的な学習教材として開発されています。  
実際の業務開発に近い環境での学習体験を提供することを目的としています。

---

## 🧪 仮想案件について

このシステムは **amoibeOJT** における仮想案件として設定されており、以下の特徴があります：

- 実在の企業要件を模倣した仕様設計
- 実務レベルの技術要件とアーキテクチャ
- 段階的な機能開発による学習進行
- 設計、実装、試験工程の実践

---

## 📁 ドキュメント構成

### 📂 設計ドキュメント

設計フェーズで作成されたドキュメント群は、`docs/設計/` フォルダーに配置されています。

#### 📂 共通設計ドキュメント

`docs/設計/共通/` フォルダーには、システム全体の共通設計ドキュメントが配置されています。

##### 📄 API システム概要.md

- **目的**: システム全体のアーキテクチャと設計方針を定義
- **対象読者**: システムアーキテクト、開発チーム、インフラエンジニア
- **主要内容**:
  - REST API サーバーとしてのアーキテクチャパターン
  - システム構成と外部システム連携
  - 部品・製品の入出荷プロセス詳細
  - 技術スタック（バックエンド技術構成）
  - データ整合性とトランザクション原則

##### 📄 API 仕様(共通).md

- **目的**: 全 API 共通の仕様とガイドラインを定義
- **対象読者**: システムアーキテクト、バックエンド開発チーム、外部システム連携担当
- **主要内容**:
  - JWT 認証とシステム権限制御
  - API 一覧（部品・製品在庫管理）
  - レスポンス形式・エラーハンドリング・冪等性制御
  - 通信セキュリティと制限事項

##### 📄 データ要件.md

- **目的**: データベース設計とデータ構造を定義
- **対象読者**: DBアーキテクト、バックエンド開発者、システム設計者
- **主要内容**:
  - 業務分離・プロセス対応・トレーサビリティ
  - ER図（概念データモデル）
  - テーブル定義（MySQL 8.0 対応）
  - 命名規則

---
